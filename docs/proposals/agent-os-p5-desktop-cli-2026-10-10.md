# P5 Desktop、CLI 与本地文件保存

本页记录 P5 交互实现及验证边界。完整阶段验收由[阶段验证报告](../verification/agent-os-p5-2026-10-10.md)记录。

## 实现

- 任务责任使用独立聚合版本更新。任务列表、目标视图和工作台显示负责人；不可用成员保留原因。责任不替代权限。
- 本地通知只提供 Host 允许的已读、未读操作，资源入口定位任务。命令使用固定版本及幂等身份。
- 当前及历史成果按计划、成果集、成果项、摘要生成 PDF、DOCX、XLSX。先生成记录，再保存文件；重试保存不生成新版本。
- Desktop 和 CLI 在保存前检查类型、长度、20 MiB 上限和明文摘要。Native 使用系统保存对话框和随机短期一次性票据；对话框返回后重新发起 Host 权限和版本检查，撤权、取消与过期不写文件；文件排他创建、权限为 0600，不覆盖已有文件或符号链接。浏览器仅报告下载已发起。
- MCP 连接显式声明范围、截止时间与读取次数。发现和导入通过持久请求查询结果，导入保留目录请求身份。受保护快照明确选入新任务后使用，正文不拼入目标。每个任务最多选入 6 份；返回更多附件时逐项选择，不静默截断。
- MCP 请求状态从 Host 恢复；重开应用后按记录读取内容，授权失效仍保留安全状态摘要，不在本地持久化正文或凭据。
- 未知变更结果保持原请求体、版本和幂等键。保存期间的工作区事件重新检查对应成果及 Asset；普通事件不取消保存，来源失效则中止。工作区切换或组件卸载仍中止在途保存。

## 聚焦证据

Desktop 静态/API/保存测试 11 项、独立组件浏览器 11 项、Native 二进制保存 4 项通过。CLI 通知零版本、请求历史查询和文件保存已纳入阶段全量基线。最终 Desktop 类型检查和构建通过。

最终真实 Host 7 个场景通过：责任分配、三格式下载及摘要验证、CLI 私有文件保存和拒绝覆盖、通知已读不验收、MCP 导入到新目标、Desktop/CLI 版本一致，以及应用刷新后恢复请求历史且不重复外部读取。没有 Host 错误响应或页面异常。

受影响旧路径：资料 5 项、草稿恢复 4 项、交付 5 项通过。P4 复用流程最终 7 项通过，覆盖技能、受保护评测、记忆确认及受控跟进，Host 错误响应为零。其首轮在设置页等待记忆卡超时，失败页面回到经营首页；保留首轮日志，未将原因归为已证实的构建干扰。

真实 P5 复验曾在 XLSX 保存等待下载时超时。独立回归证实普通工作区事件会无条件中止在途下载，修复后普通事件重新核验来源并继续；另补对话框期间撤权及对话框结束后的新检查，防止复用撤权前已开始但响应延迟的检查。三个回归和最终真实流程均通过。
