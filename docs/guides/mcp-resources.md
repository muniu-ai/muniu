# MCP 只读资料接入

Muniu 通过 Host 读取用户明确选定的 MCP 资源，并将结果保存为带来源的受保护附件。Desktop 和 CLI 只调用 Host，不直接连接远程服务器。

## 连接与导入

1. 在连接页面添加 HTTPS 端点、资料 URI 前缀、授权截止时间和累计读取次数。需要认证时，单独填写 Bearer token。
2. 请求资源目录或模板目录。每次请求都会生成持久任务；目录分页也计入读取次数。
3. 从已完成的目录中选择资源。模板支持简单的 `{variable}` 展开，变量值会编码。复杂 URI 模板会标为不支持。
4. 导入完成后，选择生成的附件交给 Agent。一个资源响应可以产生多个附件；目标保存附件的版本和摘要。

目录内容只是远程服务器返回的数据，不能授予权限。URI 只作为 `resources/read` 参数；`file://` 不会读取本机文件，`https://` 也不会触发额外网页访问。后续读取必须仍在连接授权的 URI 前缀内。

## 协议与限制

当前接入固定采用 MCP `2026-07-28` 的 Streamable HTTP 请求格式。每个请求携带协议版本、客户端信息和空客户端能力声明；仅接收 JSON 或 SSE 中匹配请求 ID 的 `complete` 结果。协议依据：[传输规范](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http)、[资源规范](https://modelcontextprotocol.io/specification/2026-07-28/server/resources)。

| 项目 | 当前限制 |
| --- | --- |
| 方法 | `resources/list`、`resources/templates/list`、`resources/read` |
| 端点 | 固定 HTTPS 域名，443 端口；不接受 URL 凭据、查询参数或重定向 |
| 网络 | 所有 DNS 地址均需为公网地址；连接固定到已核验地址并检查实际对端 |
| 单次请求 | 最长 30 秒，请求正文最多 16 KiB |
| 单次响应 | 最多 2 MiB，不接受压缩响应；SSE 最多 64 条消息 |
| 目录 | 每页最多 100 项，分页游标必须来自同一连接版本的已完成请求 |
| 导入 | 最多 20 项，总解码内容最多 2 MiB |
| 文件 | TXT、Markdown、CSV、JSON、PDF、DOCX、XLSX；解析状态沿用资料提取规则 |
| 连接授权 | 最长 366 天，每个连接及整个工作区累计最多 1,000 次请求；每个工作区最多 100 个连接 |

首版不支持远程工具执行、stdio、模型采样、服务端交互请求、订阅、OAuth 或自动打开授权网址。错误消息和服务端返回的授权 URL 不会作为操作指令执行。

## 凭据与部署

本地 Bearer token 存入 macOS Keychain 的独立服务 `com.muniu.agent-os.v2.mcp`。普通连接记录只保留凭据引用；模型凭据不会被复用。

企业部署使用 Vault KV v2 的 `muniu/v2/mcp/<scope-digest>` 路径，读取受租户、工作区、连接和凭据版本共同约束。写入使用 CAS=0；轮换创建新凭据版本。配置沿用部署中的 `MN_VAULT_ADDR`、`MN_VAULT_TOKEN`、`MN_VAULT_KV_MOUNT` 和可选 `MN_VAULT_NAMESPACE`。Vault 策略需单独授权该路径，模型密钥路径权限不能替代它。

企业生产 Worker 的 `supportedKinds` 需包含 `mcp.resource.read`。内置 production Helm 配置已包含该项；fixture 模式不声明真实 MCP 接入能力。

## 撤权与恢复

每次调用前均核验成员、连接版本、凭据版本、资料范围、授权期限和 Job 租约。网络读取前，Kernel 已保存请求正文、摘要、只读承诺及 fencing token。附件、来源记录、操作结果和 Job 完成状态在同一事务中提交。

停用、凭据轮换、成员撤权或授权到期会使旧资料引用失效。受保护附件的元数据、原文、提取内容、模型上下文和历史派生内容均重新检查来源。重新启用不会恢复旧版本引用，也不会增加读取次数或延长授权期限。

连接超时、进程崩溃等情况可能留下结果未知的请求。系统保留待核对状态，不自动重发；更换幂等键、凭据版本或同端点连接也不能重放同一远程请求。首版尚无 MCP 人工核销接口，不能通过编辑状态解除该保护。

重启后可从请求历史找回各次读取。历史列表只提供状态摘要；目录或附件需要单独读取并重新核验授权。连接停用或过期后，当前工作区成员仍能看到待核对状态，但不能读取旧资料或重新执行。

来源记录固定的是导入时的内容快照，不代表持续同步远程内容。当前不订阅远程更新；需要新资料时，用户显式发起新的读取并选择新版本。
