# 完成一次 OPC 机会验证

OPC 把想法整理为假设、证据、反证和人工决策。开始前，先完成[快速开始](../quickstart.md)，在当前工作区启用“OPC 机会验证”。本指南以 Desktop 为主；命令行入口见 [CLI 参考](../reference/cli.md#opc-与-coding)。

## 创建并界定机会

1. 在顶部“快速捕获”选择 `OPC`，输入一条机会描述，点击“捕获”。如果向导已经创建了机会，可直接使用该机会。
2. 在“OPC”页面点击“查看档案”。档案初始状态显示“待界定”；捕获不会自动开展市场研究。
3. 在“界定这项机会”填写“目标客户”“客户问题”和“可证伪假设”，点击“保存机会界定”。状态变为“已界定”后，页面会显示“开始研究”。

可用以下内容练习表单，但不要把练习假设记为真实证据：

| 字段 | 练习内容 |
| --- | --- |
| 目标客户 | 每周需要整理客户访谈的独立顾问 |
| 客户问题 | 整理耗时，且容易遗漏反对原有判断的材料 |
| 可证伪假设 | 访谈 5 位目标顾问，其中至少 2 位愿意提供真实材料参与一次试用 |

## 记录市场信号和访谈

1. 点击“开始研究”，在“记录一条市场信号”中选择来源类型，填写观察时间、原始摘录和信号摘要。
2. 将“证据关系”设为“支持当前假设”“反对当前假设”或“中立背景”，点击“保存信号”。保存后应能在档案中看到对应记录。反证和中立材料不能因为不支持方案而省略。
3. 资料足够后，点击“信号已够，开始访谈”。对实际开展的访谈填写受访者代号和时间，上传 UTF-8 文本或 Markdown，或粘贴未经改写的原文，再点击“保存访谈原文”。
4. 需要解释原文时使用“追加标注”。访谈完成后，点击“访谈已够，开始评估”。

文件信号和访谈原文先加密保存为受保护 Asset，业务记录只引用 Asset ID。上传文件和粘贴访谈原文均使用受保护存储；同时选择文件并粘贴文字时，以文件内容为准。后续标注不会覆盖原文。

## 让 Agent 辅助分析

在档案中的“给 OPC Agent 的消息”输入请求，例如“列出当前证据缺口，并指出最可能推翻假设的信号”，再点击“发送给 OPC Agent”。这一步会发起真实执行，需要可用的模型连接，可能产生模型费用及工具调用。

Agent 使用当前机会的上下文。会话会显示回答和执行状态；出现“需要你在收件箱审批”时，打开“收件箱”审阅请求。模型建议需要人工审阅，不会代替真实访谈、客户承诺或最终决策。

## 形成方案并作出决策

1. 在“形成最小收费方案”填写承诺结果、服务范围、不包含事项、价格假设、交付周期和验收方式，点击“保存最小收费方案”。
2. 记录真实的行动承诺或付费证据，填写可复核的来源，点击“提交待确认承诺”。
3. 对照原始记录，在“核对客户承诺”确认真实性。只有人工确认后，证据等级才会提升。不要为了推进页面而填写虚构承诺。
4. 出现“作出最终决策”后，选择“继续推进”“修订方案”或“停止机会”，填写理由并确认，点击“保存人工决策”。

当前 Desktop 在最小收费方案后，会先引导记录并确认客户承诺，再展示最终决策表单。如果暂时没有真实承诺，可在“管理机会”中说明原因并暂停；已有证据会保留。“放弃机会”需要明确确认，放弃后不能恢复。

OPC 不自动联系客户、发布内容、发送报价或收款。上述操作记录的是验证材料与负责人判断。

## 导出六项成果

完成最终决策后，点击“导出 6 项成果”。成果包括机会验证档案、访谈包、证据账本、反证清单、最小收费方案和决策记录。

macOS 会显示保存对话框并创建 JSON 文件。导出不覆盖同名文件；取消后可以再次保存，不会重复生成成果。单份文件上限为 20 MiB。

导出文件含经授权读取的明文访谈资料。保存前确认路径，分享前检查接收范围；文件分享后无法撤回。
