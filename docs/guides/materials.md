# 任务资料与业务来源

委派任务时可选择文件，或从客户、订单、交付和复盘页面点击“交给 Agent”。目标保存来源版本和摘要，不把文件正文放进目标描述。开始执行前，Host 重新核对来源与当前权限，提取获准内容并保存本次执行的来源清单。

## 文件范围

支持 UTF-8 文本、Markdown、JSON、CSV、含文本的 PDF、DOCX 和 XLSX。PDF 保留页码；文档保留段落或部分定位；表格保留工作表和单元格定位。JSON 作为文本读取，不执行其中的内容。

“已解析”表示解析器提取了支持的文字内容，不表示理解了排版、图片或整个文档。扫描 PDF 不做 OCR，密码保护文件不尝试解密；无法读取或只提取部分内容时会明确提示。DOCX 与 XLSX 不执行宏、脚本、外部链接和公式；公式只使用已有缓存值，缺少缓存时提示不完整。

解析有文件大小、正文长度、页数、表格单元格及压缩包展开限额。超过限额时停止，可缩小文件范围或改用文本。Office 文件拒绝危险路径、实体声明和异常压缩包结构。PDF 在可终止的独立解析进程中读取，资源不足或超时不会转为 Host 内直接解析。

## 模型实际读取什么

短资料完整纳入；资料超出分配空间时，按目标和验收条件执行确定性的中英文关键词检索，选入完整原文段落，并保留原始定位。总资料选段空间为 16 KiB，多份文件均分。没有任何完整段落能放入时停止，不截断段落后声称它是完整事实。

发送内容明确标注解析状态、资料总段数和实际选段数。模型须注明来源，缺少证据时不能自行补全。原文提取结果与模型实际选段是两件事：资料预览可用于核对解析，不能据此断言模型已阅读全部文件。

每次模型调用有独立输入限制，目标累计 token 额度不能扩大它。必要目标、验收要求和当前指令保留；先缩减大的工具结果，再摘录已有历史，仍放不下时停止。摘录保留受保护原文记录的引用和摘要，不替代原始事实。实际请求及其来源、选取清单在外发前持久保存。

## 资料失效与撤权

读取、开始执行和模型或工具工作前均重新检查来源。来源版本变化、资料删除或读取权限撤销后，后续读取与外发会停止。依赖该来源的历史答复也不能通过新一轮会话绕过检查。研发列表、首页和成果列表会隐藏失效来源派生的正文，显示重新核对提示。

已经发出的外部请求无法据此撤回。撤权后返回的结果不能继续派发工作，但已发生的费用仍保留并结算。未知结果仍按原有核对流程处理，不能直接重跑。

## 业务对象

业务委派只读取选定对象及必要关联事实。客户联系方式和其他客户资料不会自动加入。订单金额、待收余额和客户验收状态由经营领域规则生成，模型不能通过答复改写台账。

首版引用固定整个经营聚合的版本；其他经营记录变化也可能使旧引用失效。这是保守的失效策略，重新核对后才能用于新任务。采纳 Agent 建议、登记客户确认、接收内部成果、客户验收和收款仍是不同操作。

CLI 可以上传受保护文件、读取提取结果及业务对象上下文，再把返回的版本引用写入目标 JSON。具体命令见 [CLI 参考](../reference/cli.md)。

## 从 MCP 导入资料

已授权连接的资源可导入为带来源的受保护附件，再在委派时显式选择。请求历史在 Host 中保存，重启后可继续查看；目录与正文读取重新核对当前授权。停用连接或轮换凭据后，旧资料引用不会自动恢复。配置、限额和恢复边界见[MCP 只读资料指南](mcp-resources.md)。
