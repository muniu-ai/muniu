# 木牛 v0.2.0 发布说明

v0.2.0 把木牛的首方客户端和企业入口统一到 app-server v2，并将 Agent 状态升级为 `Thread → Turn → Item` 与 `AgentEventV3` 事实链。这是破坏性协议升级；部署前必须按 [迁移指南](../migration-v0.2.md) 停写、备份、演练和转换。

## 主要变更

- 新增私有 workspace `@mn/app-server-protocol`、`@mn/app-server` 和 `@mn/sdk`。Zod schema 生成 TypeScript 类型、JSON Schema 与方法目录。
- 实现固定 Codex 提交 `99660ab3c7b861c916e467581fa9b8723504d66b` 的 app-server v2 稳定子集；木牛能力使用 `muniu/*` 命名空间。
- 新增 stdio、owner-only Unix socket、带 bearer token 的回环 WebSocket，以及使用 TLS、OIDC/JWKS、租户隔离和方法级 RBAC 的企业 WSS。
- 新增 Thread/Turn/Item 投影、目标与预算、steer、interrupt、上下文压缩、附件、结构化输出、CAS spill、崩溃与审批恢复。
- 新增受治理的 MCP、typed contributor bus、插件 manifest、skill 运行时和持久化多 Agent 图。
- CLI、Worker 协调器和 Desktop 改用同一个 SDK。Desktop 支持实时 item、审批、计划/差异/终端、子 Agent 图和证据 JSON 导出。
- 新增本地与 PostgreSQL/S3 V1/V2→V3 迁移器、只读归档、摘要映射和受新写入保护的 rollback。
- 删除公开控制 REST/SSE 协议。HTTP 只保留运维与受控内容端点；内部 Fastify route 仅供 `muniu/*` handler 调用。

## 升级要求

1. 停止所有 v0.1 写入方并完成全量备份。
2. 在生产副本执行 dry-run 和 apply 演练。
3. 正式迁移后一次性升级 API、Worker、CLI 和 Desktop。
4. 在首次 V3 写入前完成回退决定；此后只能恢复整套备份。

## 已知边界

v0.2.0 不包含 Codex Rust 内核、Python SDK、远程 daemon、设备配对、realtime voice 或 computer use。OpenAI account/login、托管 marketplace、自动 updater、匿名标识和反馈上传也不在发布范围。

所有第一方 npm workspace 仍为 private。macOS Desktop 只做构建和打包验证，不发布签名、公证或自动更新制品。

协议范围见 [兼容矩阵](../compatibility-v0.2.md)，接入方式见 [app-server 文档](../app-server.md)。
