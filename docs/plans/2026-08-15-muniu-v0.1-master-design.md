# 木牛 v0.1.0 开源升级总设计

> **执行要求：** 使用 `dev-executing-plans` 逐任务执行此计划；计划执行不绑定任何外部 Agent CLI。

**目标：** 在保留木牛治理控制面的前提下，以不依赖 Claude Code/Codex CLI 的内嵌 Agent 内核执行模型会话，并发布 v0.1.0 Developer Preview。

**架构：** Spec、Governance、Harness、七阶段 Loop、验证和证据仍是外层控制面；内嵌 Agent 仅负责候选执行。选择性适配 DeepSeek Harness 固定提交的 Agent、Session、Tool、Scope 和 LLM 核心闭包，通过木牛稳定接口暴露能力。

**技术栈：** Node.js 22.19.x、npm 11.10.1、TypeScript 5.7、Fastify 5、Tauri 2、Rust、SQLite/PostgreSQL、REST/SSE。

**当前依赖边界：** 内嵌 Agent 直接调用配置的模型 Provider API，木牛启动和 Agent 会话不要求安装 `claude` 或 `codex`。`AgentRuntimeId=claude|codex` 仅表示可选 legacy 兼容适配器，不得成为 builtin 路径的隐式 fallback。

## 决策基线

- 产品和仓库名为 Muniu / 木牛，CLI 为 mn，canonical 仓库为 https://github.com/muniu-ai/muniu。
- 首发包含源码、macOS arm64/x64 Node 22 portable 包和 GHCR API/demo 镜像；不发布 npm 包或签名/公证桌面 App。
- 新代码 Apache-2.0 + DCO；适配的 DeepSeek Harness 代码保留 MIT 许可与版权，固定来源提交为 47f943859bef60e4160492346772ded9b24f765a。
- 本地优先、遥测默认关闭；只有选中的上下文发送给配置的模型 API。
- macOS 12+ 为唯一正式宿主平台。Seatbelt + canonical worktree 是 Developer Preview 防护，不宣称 Docker 等级隔离。

## 顺序与依赖

1. 执行 01 开源基线，建立可信仓库、依赖、许可和 CI 基线。
2. 01 通过后执行 02 内嵌核心；任何上游文件迁入时同步扩展 provenance。
3. 02 的稳定协议完成后执行 03 模型/会话；03 的事件和审批协议以及企业 PostgreSQL/S3 会话后端是 04、05 的前置依赖。
4. 内嵌 Agent 会话已独立于外部 CLI；04 工具安全边界通过后，05 再把 builtin runtime 接入既有 `task/run` 治理 Loop 的默认候选执行路径。
5. 01 至 05 全部退出门槛通过后执行 06；发布制品只能由受保护 CI 生成。

每份子计划使用独立 worktree 和小提交。跨计划发现缺口时先更新本总设计和受影响子计划，不在当前计划顺手扩展范围。

## 稳定公共接口

- AgentRuntimeId = builtin | claude | codex；ModelProviderId 为独立字符串标识。
- ExecutionStrategyV2 分离 runtimeIds 与 modelProviderIds，同时兼容旧 providers 输入一版。
- AgentExecutionBindingV1 绑定 runtime、provider/model、session 和不可变 HarnessBindingV1。
- AgentSessionEventV1 使用单调 seq 和 digest 形成 append-only 事实流。
- REST/SSE 暴露 agent session 创建、读取、消息、事件续传、取消、关闭和审批；所有变更请求携带 clientRequestId。
- 固定端点为 POST /v1/agent-sessions、GET /v1/agent-sessions/:id、POST /v1/agent-sessions/:id/messages、GET /v1/agent-sessions/:id/events?after=<seq>、POST /v1/agent-sessions/:id/cancel、POST /v1/agent-sessions/:id/close、POST /v1/agent-sessions/:id/approvals/:approvalId。
- 审批决策固定为 approve_once、approve_session_scope、deny；破坏性操作不得使用 session-scope 永久授权。
- CLI 新增 mn agent run --prompt、mn agent chat、mn agent resume <id>、mn agent sessions；既有 mn task create 和 mn run 保持兼容。

## 默认与兼容边界

- 默认 Provider preset 为 deepseek-official / deepseek-v4-flash，可选 deepseek-v4-pro，并提供 OpenAI Chat/Responses 与 Anthropic Messages adapter。
- 本地会话事实源为权限 0600 的 append-only JSONL，SQLite 是可重建投影；密钥继续使用加密 secret store。
- ~/.mniu、mniu://、MN_MNIU_ROOT、旧数据库名和历史任务兼容一版；canonical 状态目录与 deep link 为 ~/.muniu 和 muniu://。
- v0.1 不提供 DSH Session importer、任意代码插件、任意 URL fetch、未签名第三方扩展或裸跑 sandbox fallback。
- 已发布 v0.1.0 制品不可覆盖；修复必须发布 v0.1.1。
