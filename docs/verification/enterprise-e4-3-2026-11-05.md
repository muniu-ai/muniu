# E4.3 验收记录

2026-11-05。基线为 E4.2 出口 `484566b`，分支 `codex/enterprise-e4-3`。本包已完成实现，下列本地工程与合成数据检查通过。真实离线质量和试点仍未验收。

## 实现与边界

新增受保护知识版本、来源权限传播、精确引用、成果固定与人员验收、候选经验启停、五套不可变流程版本及统一 Host 接口。业务事实快照和人员决定分别来自已存在的业务数据与验收记录。模型文字不能生成交易事实。说明见[知识、成果与流程](../enterprise-knowledge-workflows.md)。

知识输入使用 E4 的同一原生 Worker、预算与授权体系。撤回来源会阻止后续读取和结果传播；已知模型费用仍结算。财务复盘作为 Agent 来源时继续检查其原始订单权限，不能通过复盘快照绕过字段隔离。

五套流程的本地测试覆盖只读分析、候选成果和人员验收，保留业务对象值不变。正式业务写入由 E2/E3 约束，提供方连接由 E5 接入。本包没有执行真实 Sales、企业微信或真实模型业务评测。

## 失败、修复与资源

- 较大的合法流程配置曾被通用请求上限拒绝。现按接口设置有界正文上限，并验证权限拒绝仍正常生效。
- 流程版本超过响应契约上限时曾可先落库。现每套流程最多保存 100 个版本，超限在写入前拒绝，旧版本仍可读取与回退。
- 首轮 Linux 镜像遗漏 E0.2 冻结任务文件，308 项产品测试通过，评测测试因文件缺失失败。只补入原摘要对应的两个基线文件后，该轮 315 项全部通过；已有制品校验和未变化。
- Linux 导出复验还发现退出采样竞态：本地观测到 RSS 字段消失，而进程内存记录已全部归零。现依据[内核字段定义](https://www.kernel.org/doc/html/latest/filesystems/proc.html)核对零地址空间或已结束状态，再等待原退出结果；运行中数据不明仍拒绝，堆、RSS、超时和输出上限不变。三种格式及相关权限回归 32 项通过。
- 模型伪造的资料定位被拒绝；模型在途撤回来源后不保存成果，保留实际发生的已知费用。

构建、测试和容器门禁串行执行，宿主 Node 堆限制 512MiB。完整 Node 进程树 RSS 采样峰值 522.6MiB，sidecar 构建峰值 573.2MiB。Linux 容器限制 512MiB、0.75 CPU，采样峰值 165.3MiB；PostgreSQL 容器限制 192MiB，采样峰值 89.64MiB。组合部署容器在同一采样时刻的总量峰值为 586.59MiB。各已完成门禁的采样记录中，系统空闲内存最低为 27%。

验收使用匹配外部依赖锁文件的缓存镜像，未重新编译 MinIO。组合部署清理退出码为 0，原有 11 个服务的标识、启动时间和运行状态前后相同。本次数据库与 Linux 容器也已退出。命令、资源采样、制品和日志摘要见[机器可读证据](enterprise-e4-3-evidence-2026-11-05.json)。
