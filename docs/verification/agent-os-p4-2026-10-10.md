# Agent OS P4 验证记录

日期：2026-10-10。分支：`codex/agent-os-p4-reuse`，基于 P3 `2061ae5`。范围见[批准计划](../proposals/agent-os-delivery-2026-10-10.md)及[P4 实施记录](../proposals/agent-os-p4-reuse-2026-10-10.md)。本地源码、界面与工程基线已完成验证；真实模型质量和企业环境限制单独列明。

## 功能与约束

团队技能从已验收的固定团队计划和成果生成不可变版本，保留角色、输入输出、依赖、独立复核、权限需求和检查规则。新任务显式选择固定版本，重新配置资料和预算；启用与推荐需要独立实测评测证据。停用和回滚不更改在途计划。

记忆区分事实、偏好、用户来源及模型来源。模型提案由真实执行补足来源，用户确认后才参与关键词选择；每次采用的版本、来源、共享授权与实际发送内容写入同一受保护请求。资料撤回、共享撤销或过期都会阻止后续读取和外发，历史业务快照不能让过期记忆重新有效。

主动跟进绑定未关闭的经营目标和业务对象，限只读内置单执行者。创建时明确授权资料、有效期、单次额度、24 小时或 7 天周期额度及累计次数。每次相关变化原子保存新会话、新目标、触发记录、预算预留及唤醒意图，再以稳定幂等键规划和派发；无关台账变化不调用模型。每轮最多检查 20 个策略，按轮转顺序恢复，不持续占用 Worker。

待验收和可返工任务继续占用单次额度的剩余部分。未知费用不计零，停止、取消、重启和新周期不能释放尚未核对的费用；发生费用归属原触发周期。新结果、失败或需要决定的事项产生本地通知，通知直接定位目标。没有相关变化时不重复通知。
