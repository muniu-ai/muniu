## 已发现并修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| 有批准操作和价格字段许可，但没有实际读取许可时仍可能批准 | 批准前分别检查批准权、读取权及关键字段交集；新增无读取权、仅可读取普通字段的反例 |
| 加密准备期间登录尝试或会话到期，命令仍可能提交 | 事件仓库新增同步提交前检查；登录、身份命令、权限配置和额度配置在提交前重新检查当前会话或期限 |
| 另一实例注销会话后，旧请求仍持有有效成员版本 | 浏览器主体携带服务端会话标识；会话状态从已提交事件重建，版本冲突后重算当前会话，拒绝旧请求 |
| 企业容器 Host 在业务初始化之前退出 | `scripts/enterprise-host.mjs` 的 shebang 位于导入语句之后，`node --check` 可复现语法错误；将其移到首行，并为四个企业入口增加语法检查 |

上述反例均先失败，修复后复验。新增提交检查发生在异步加密完成之后、事实事务提交之前。因并发变化发生的版本冲突仍会回滚并重新读取事件；未修改事件事实来源或增加旧状态加载路径。

浏览器主体的会话标识只由 Host 从已验证会话生成，不接受客户端自报。受信的非浏览器调用仍由 Host 构造主体；这不代表第三方插件可以自行授予身份。

## 资源约束与剩余出口
