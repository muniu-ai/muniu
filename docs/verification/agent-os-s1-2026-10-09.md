## 新增行为与回归证据

| 范围 | 验证内容 |
| --- | --- |
| Kernel 原子提交 | 目标绑定与 Execution、Authority、Job 同事务；故障整体回滚，相同请求不生成第二个执行 |
| Goal 核心 | 不可变计划、准确版本授权、同 Thread 互斥、预算预留与核费、取消意图、交付摘要和逐项人工验收 |
| 事实恢复 | 通过受保护 journal 和 CAS 重建产品事实；缺少密钥或内容完整性不符时拒绝恢复 |
| Host 与 Worker | 固定模型、资料和任务输入；派发来源标记缺失时拒绝执行；原会话入口不能绕过目标计划 |
| OPC | 真实 Worker 使用固定模型响应，形成版本化答复；没有人工复核条款不能接收 |
| Coding | 临时 Git 仓库、真实 macOS 沙箱和 Gate、候选批准及统一验收；篡改实际 diff 后验收被拒绝 |
| 取消与撤权 | 持久取消指令及时终止在途进程；确认终止且工具全部结算后才取消，未知结果继续待核对；成员撤权后后台继续核对已发生费用，不形成新交付 |
| 后台观察 | 自动同步执行结果；无变化观察不写事件、回执、outbox 或投影，也不发起模型请求 |
| CLI | 列表、版本必填、固定计划启动、冲突不重试、成果摘要及条款提交；新增测试接入默认入口 |
| Desktop | 创建、计划确认、启动、取消、自动出现成果、逐条复核和接收；来源变化后清理旧预览，迟到响应不能恢复正文；外部创建目标时列表自动更新，旧响应不能覆盖新列表 |
