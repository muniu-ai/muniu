# Agent OS P1 验证记录

日期：2026-10-10。分支：`codex/agent-os-p1-context`，包含已完成的 P0 改动。范围见[批准计划](../proposals/agent-os-delivery-2026-10-10.md)。当前工作树尚未合并主线。

## 本轮范围

- 委派资料保存为受保护 Asset；目标记录来源版本，不再嵌入整个文件。支持文本、Markdown、JSON、CSV、含文本 PDF、DOCX 和 XLSX，保留页码、段落、工作表和单元格定位。
- 解析结果区分完整、部分和无法读取；不执行宏、脚本、外部链接或表格公式。Office 解析检查压缩包路径、展开量和 XML 边界；PDF 使用可终止的独立进程。
- 按目标和验收要求进行有界关键词选段；模型调用前保存完整请求和实际来源清单。超额时优先卸载工具结果，再压缩历史；必要输入放不下时停止。
- 客户、订单、交付和复盘支持业务对象委派。当前经营聚合版本变化后旧引用失效，模型答复不能修改经营事实。
- 读取、模型调用、工具执行和成果验收重新检查来源。撤权后隐藏派生正文、阻止后续外发，已发生费用仍保留。Desktop 与 CLI 使用相同 Host 契约。

本轮尚不提供持久团队、多成果返工、团队技能或主动跟进；这些功能在后续阶段实现。资料预览表示提取覆盖，不能当作模型已完整阅读的证明。

## 实际边界

PDF 解析默认限制两个并行进程、六个排队任务、五秒总期限、128 MiB V8 堆及 256 MiB RSS 检查阈值。RSS 通过采样终止超限进程，是检查阈值，不是内核强制分配上限；短暂超额仍可能发生。macOS 路径与打包后的 PDF 子进程已实测，Linux 路径尚未取得实测结果。

上下文采用保守字节估算和固定输入上限，不宣称等同于所有模型的实际分词。资料选段总空间为 16 KiB；当前没有向量数据库、OCR、复杂版面还原或公式计算。业务引用固定整个聚合版本，可能因无关业务记录更新而保守失效。

测试使用脱敏或合成资料及测试模型，未产生真实模型基准、首次验收率或成本降低成绩。P0 质量门仍未测量，不能据此启用团队自动推荐。现有用户应用占用的旧版 Host 未被停止，完整安装包启动验收仍需独立验证环境。本记录不构成发布、Apple 公证或生产部署验收。
