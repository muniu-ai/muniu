## 功能与约束

MCP 通过固定 HTTPS 端点接入只读资源。发现、分页和读取均保存完整请求、当前授权、持久 Job 与外发承诺；Worker 按租约和 fencing token 提交结果。连接停用、授权版本变化、成员撤回或到期后，导入快照停止读取与传播。远程权限变化无法离线即时获知；不执行远程工具、采样、远程授权网址或 stdio 程序。

DOCX、PDF、XLSX 导出固定目标、计划、成果条目和摘要，保留来源及验收状态。DOCX 保存文本与来源，不含宏或外部关系；XLSX 以文本单元格保存内容，不执行公式；PDF 使用固定摘要的 Noto Sans CJK SC 字体。导出支持有界文本成果，不将任意 Markdown 或复杂表格声称为排版还原。

导出在独立进程执行，最多并行 2 个、排队 6 个，整体期限 15 秒。V8 堆限制为 256 MiB；每 25 ms 检查进程 RSS，超过 384 MiB 时终止。这是采样终止阈值，不是内核级硬内存分配上限。必需的受限执行条件不可用时停止导出。

导入和导出复用受保护 Asset。加密准备后，Kernel 事务重新检查权限，原子保存附件、密钥、来源及操作结果。元信息、下载、提取、记忆、技能和模型上下文均追溯派生来源；原成果凭据、Coding Gate、来源或密钥失效后停止传播。机会访谈原文的实际读取也写入执行来源清单。

责任分配保存独立版本，只能分给当前所有者或操作员，不转移执行授权或验收权限。分配、交付与需处理状态产生本地去重通知；已读状态独立保存，通知直达任务。原任务变化或重新分配后隐藏失效通知。未接入外部消息渠道。

## 聚焦验证

- MCP 覆盖 JSON/SSE、分页、多内容、URI 模板、限额、私网地址拒绝、撤权、并发派发、陈旧租约及未知结果禁止重放。请求状态可在重新打开应用后恢复；停用连接后只保留安全状态摘要。
- 派生 Asset 覆盖原子提交、来源闭包、跨工作区、循环引用、解密期间撤权、密钥删除及重新进入模型。OPC 模型清单记录实际读取的业务事实和附件，并在异步读取后重新检查权限。
- 导出覆盖三种格式的独立提取、固定成果版本、内容摘要、公式注入、来源撤回及重建。使用独立阅读器检查中文实际渲染：PDF 一页、DOCX 一页、XLSX 两页；检查内容、金额和完整来源摘要。字体保留原始 OFL，固定来源提交与文件摘要。
- 责任分配覆盖成员资格、版本竞争、幂等重试和事件重建；通知覆盖去重、已读版本、重新分配及资料撤权。责任不转移执行授权，已读不改变成果验收。
- 企业身份首次登记覆盖并发、已有禁用身份、身份类型与租户冲突及事件重建；登记不授予工作区成员资格。
- 最终界面复验发现普通工作区事件会取消文件下载。补充失败用例后，将事件处理改为重新核验当前成果与附件；普通变化继续保存，来源失效中止并提示。独立复核还发现最终保存可能复用对话框打开期间发起的旧检查，补充失败用例后改为对话框结束后重新读取。对话框期间撤权时销毁一次性票据，不写文件。

上述模型输出和 MCP 响应使用合成替身。企业身份测试使用 enterprise profile、注入的可信身份解析器、SQLite、FileCas 和内存密钥；网络边界、Vault 与 Keychain 分别使用请求或命令替身。这些测试不构成真实 OIDC、远程 MCP 服务、Vault 或系统 Keychain 的部署兼容性证据。
