# Agent OS 桌面验收清单

## 用户可见结论

- 首次使用只有四屏，不要求填写 Provider ID、Model ID、Base URL 或 wire format。
- 经营视图和专业视图使用同一工作区与领域接口，只改变信息密度。
- 首页、工作区、收件箱、成果、活动始终可用，技术配置默认折叠。
- OPC 先显示证据、反证、缺口和下一步；没有承诺证据时显示“方案待验证”。
- Coding 先显示任务、差异、检查、审批和下一步；Harness、候选数和预算只在专业视图展开。
- 单个插件失败时显示插件级降级提示，不影响 Shell 和其他页面。
- Cmd-K 可以搜索命令、机会、Coding 任务、Skill 和成果。

## 功能与视觉检查

| 控件或状态 | 功能检查 | 视觉检查 |
| --- | --- | --- |
| 四屏向导 | 完成视图、插件、BYOK、工作区与首个对象 | 1180×760 首屏无横向溢出，主操作可见 |
| 视图开关 | 经营→专业→经营完整循环，请求路径保持一致 | 专业详情原位出现，经营结果卡不变 |
| 快速捕获 | 当前工作区生成机会或 Coding 任务 | 输入、类型和主操作在同一行 |
| Cmd-K | 键盘打开、搜索、关闭 | 遮罩、层级、焦点和结果密度清晰 |
| 审批 | 展示意图、资源、风险、有效期并完成一次决定 | 危险与批准操作有清楚区分 |
| OPC 降级 | 首次失败后 Shell 仍可导航，重试恢复 | 降级卡不遮挡首页与侧栏 |
| OPC 文件来源 | 选择证据文件后先上传受保护 Asset，信号与访谈命令只提交 Asset ID | 文件名、大小、上传说明和错误在当前任务内可见 |
| Coding 结果 | 查看差异、检查、审批、下一步 | 960×640 最小窗口无横向溢出 |

探索场景：插件首个请求返回 503 后恢复；最小窗口打开专业详情和 Cmd-K。
